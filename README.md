# Groyper Habit Tracker

A daily habit tracker PWA (vanilla JS, HTML, CSS) with a Groyper frog that reacts to your score, plus a weather-reactive background.

The frog has five stages. At the top stage (80-100) it sits in the steeple pose in thug life shades, a gold chain and an iced-out watch.

## Run locally

Double-click `start-server.bat`, or serve this folder with any static server.

## Hosting

Static files only. Served from GitHub Pages (Settings > Pages > Deploy from branch > `main` / root).
All asset paths are relative, so it works under a repo sub-path.
